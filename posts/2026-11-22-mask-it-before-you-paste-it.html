Mask it before you paste it

This was a Sunday project. I'd been meaning to make time for it, because I think a lot of people could use it.

Would you paste this email into an AI tool? It has a name, a phone number, a tax file number and a Medicare number. All fake.

So I masked it first, on my own laptop.

The tool is Presidio, an open-source project Microsoft started and the community now runs (MIT licence). I used Claude Code to wrap it in a single command. It read the email and swapped each detail for a label like <PERSON> or <AU_TFN> in a few seconds. Nothing was sent anywhere, because the language model runs locally. That part matters: if you send personal data to an AI to remove personal data, you've already shared it.

It isn't perfect. In my tests it caught names, emails, phone numbers, a street address, and Australian TFN and Medicare numbers. It missed a staff ID and a health detail ("off sick with anxiety"). Masking is a first pass, and a person still reads the result.

Why bother if your organisation has enterprise Copilot? Microsoft says prompts and responses in Copilot are covered by its data protection terms and aren't used to train foundation models. That's real protection. But when Copilot searches the web, a short query goes to Bing, which Microsoft handles separately from Microsoft 365. And none of it covers the free tools people use on the side.

Masking before you paste is a habit worth teaching, whatever tool people use.
